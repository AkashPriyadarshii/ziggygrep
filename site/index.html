Literal grep in pure Zig

Ripgrep speed, one static binary, zero excuses.

Recursive search scans every byte on every query. ziggygrep cuts the cost per byte instead of indexing around it. First byte prefilter skips what cannot match, line bounding runs on verified hits only. Output matches rg -F on all 7 test patterns.

Why it earns a slot

Less work per byte, not work avoided.

No index to build, no daemon to feed. Each stage removes cost that regex pipelines pay on every file.

  • Literal-first engineFirst byte prefilter plus eql verify. Positions that cannot start the pattern cost one memchr step, zero slicing.
  • Threaded file sweepFixed fetchAdd(8) batches from one file list, per worker scratch buffers, files sorted at merge. Lists of 8 or fewer files run direct.
  • Fused scan plus formatHeaders built once on the stack, written once into the buffer. No span array, no second pass.
  • Flat memoryStreaming reads, no mmap, 256 KB accum with one flush, 60 KB pipe-safe chunks. Works on pipes.

Internals

Three stages, zero wasted bytes.

01

Prefilter, then confirm

Vector first byte scan skips 32 bytes per step. Line bounding runs on verified hits only. Same line hits dedupe, finished lines jump past.

02

Batch steal, sorted merge

Atomic index hands out fixed batches. Each worker owns scratch, carry, and chunk buffers. Merge sorts by file for deterministic output.

03

Buffer, then one flush

Headers built on the stack, written once. Pipes cap transport at 60 KB chunks. No mmap, flat memory, pipe safe.

Quickstart

One clone, one build, first hit in a minute.

Needs Zig 0.16.0 only. No packages, no services, no accounts.

git clone https://github.com/AkashPriyadarshii/ziggygrep.git
cd ziggygrep
zig build -Doptimize=ReleaseFast
./zig-out/bin/ziggygrep HashMap .
  1. Search one pattern
    Run ziggygrep TODO src/main.zig. Matches print as path:lineno:line.
  2. Count or list
    Run ziggygrep -c HashMap . for counts, ziggygrep -l fn . for file names.
  3. Pipe it
    No paths means stdin. Exit 0 match, 1 no match, 2 error. Alias zgg if you type it daily.

Limits

What it refuses to be.

  • No regexPatterns are literal bytes. Use ripgrep when you need regex.
  • No .gitignore in v0.1Dotfiles and .git are skipped; full ignore support is planned.
  • No colors, context, JSONNot in v0.1. Pipe to less when you want paging.
  • No index, no daemonEvery query scans. That is the design.
